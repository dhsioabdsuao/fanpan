## 待补齐神煞

以下按《渊海子平》《三命通会》典籍记载顺序排列。共 **22 颗**。

---

### 1. 天厨贵人

- **类别**: 贵人
- **出处**: 《渊海子平》卷一·论天厨贵人
- **原理**: 食神之禄位。甲食丙（丙禄巳），乙食丁（丁禄午）……
- **查法**: 年干+日干 → 地支

| 干 | 食神 | 食禄 | 天厨地支 |
|----|------|------|----------|
| 甲 | 丙 | 巳 | **巳** |
| 乙 | 丁 | 午 | **午** |
| 丙 | 戊 | 巳 | **巳** |
| 丁 | 己 | 午 | **午** |
| 戊 | 庚 | 申 | **申** |
| 己 | 辛 | 酉 | **酉** |
| 庚 | 壬 | 亥 | **亥** |
| 辛 | 癸 | 子 | **子** |
| 壬 | 甲 | 寅 | **寅** |
| 癸 | 乙 | 卯 | **卯** |

- **判定**: 取年干+日干对应地支 → 查四柱地支（四柱均可） → 命中柱位即得天厨贵人
- **文案**: “天厨贵人，食禄丰足，福慧双修，一生不愁衣食”
- **洛阳女命**: 年干甲→巳，时柱辛巳 → **命中**

### 6. 天赦

- **类别**: 贵人
- **出处**: 《渊海子平》卷一·论天赦
- **原理**: 季节性赦免日——春戊寅、夏甲午、秋戊申、冬甲子
- **查法**: 月支定季节 + 日柱干支

| 季节 | 月支范围 | 天赦日 |
|------|---------|--------|
| 春 | 寅卯辰 | **戊寅** |
| 夏 | 巳午未 | **甲午** |
| 秋 | 申酉戌 | **戊申** |
| 冬 | 亥子丑 | **甲子** |

- **判定**: 以月支定季节，查日柱干支是否对应天赦日
- **文案**: “天赦，逢凶化吉，遇难呈祥，一生少刑狱之灾”
- **洛阳女命**: 月支戌=秋，天赦戊申，日柱乙酉 → 不命中

### 7. 天罗地网

- **类别**: 凶星
- **出处**: 《渊海子平》卷一、《三命通会》卷三
- **原理**: 年柱纳音定五行命，再查辰戌巳亥
  - 火命人见**戌亥**为天罗
  - 水土命人见**辰巳**为地网
  - 金木命人无天罗地网
- **查法**: 年柱纳音定命 → 查四柱地支

年柱纳音对照（六十甲子纳音取五行）：

| 年命五行 | 天罗 | 地网 | 判定 |
|----------|------|------|------|
| 火 | 戌、亥 | — | 见戌或亥为天罗 |
| 水 | — | 辰、巳 | 见辰或巳为地网 |
| 土 | — | 辰、巳 | 同上 |
| 金 | — | — | 无 |
| 木 | — | — | 无 |

- **判定**: 需取年柱纳音五行。命中对应地支即出。天罗地网不限柱位
- **文案**: “天罗地网，运程阻滞，有志难伸。男子忌天罗，女子忌地网”
- **洛阳女命**: 甲申年=泉中水（水命），地网在辰巳。地支申戌酉巳，巳在时柱 → 时柱应得地网。但需确认：巳为时支，时柱是否计地网？传统不限柱位

### 12. 天德合

- **类别**: 贵人
- **出处**: 《渊海子平》卷一·论天德贵人（附）
- **原理**: 天德所在天干/地支的相合者。天干用五合（甲己、乙庚、丙辛、丁壬、戊癸），地支用六合（子丑、寅亥、卯戌、辰酉、巳申、午未）
- **查法**: 先取天德贵人位置，再求其合神 → 查四柱

| 月支 | 天德 | 合神 | 天德合 |
|------|------|------|--------|
| 寅 | 丁 | 丁壬合 | **壬** |
| 卯 | 申 | 申巳合 | **巳** |
| 辰 | 壬 | 丁壬合 | **丁** |
| 巳 | 辛 | 丙辛合 | **丙** |
| 午 | 亥 | 寅亥合 | **寅** |
| 未 | 甲 | 甲己合 | **己** |
| 申 | 癸 | 戊癸合 | **戊** |
| 酉 | 寅 | 寅亥合 | **亥** |
| 戌 | 丙 | 丙辛合 | **辛** |
| 亥 | 乙 | 乙庚合 | **庚** |
| 子 | 巳 | 巳申合 | **申** |
| 丑 | 庚 | 乙庚合 | **乙** |

- **判定**: 天德为天干 → 查四柱天干中是否出现合神；天德为地支 → 查四柱地支中是否出现合神。命中即得
- **文案**: “天德合，与天德贵人相合，化煞解厄，福泽绵长”
- **洛阳女命**: 月戌→天德丙→丙辛合→辛。时干为辛 → **命中**

### 14. 亡神

- **类别**: 凶星

- **查法**: 年支+日支+月支 → 地支（参照该支所属三合局）

| 三合局 | 劫煞（绝） | 亡神（临官/旺） |
|--------|-----------|----------------|
| 申子辰 | 巳 | **亥** |
| 寅午戌 | 亥 | **巳** |
| 巳酉丑 | 寅 | **申** |
| 亥卯未 | 申 | **寅** |

- **判定**: 以年支、日支、月支分别查其所属三合局，取亡神地支 → 查四柱地支中命中者
- **文案**: “亡神，自内失之，主心性难定、官讼牢狱。吉则足智多谋、处事严谨”
- **洛阳女命**: 日支酉（巳酉丑）→亡神申，年柱甲申 → **命中**
- **注**: 当前劫煞已实现（年支+日支），亡神应同步加上月支参照
