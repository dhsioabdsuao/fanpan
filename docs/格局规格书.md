## 第〇章 · 从格/化格先行判定(全局性质层)

从格与化格是独立于八格体系的"全局性质"判定,在取格之前按固定顺序先行,命中即定,后续只按该体系论。

### 0.1 优先级链(顺序固定)

① 化格 → ② 从格 → ③ 化刃为印特例 → ④ 正格体系(八格/建禄月劫/阳刃,见第一章)。

### 0.2 从格判定**不依赖强弱模块**

从格条件只取自身三项:**日主无根** + **从神得令成势** + **无破格因素**。判定中不查询《强弱规格书》的任何结论。

依据:【滴天髓原文】"从得真者只论从"——从格一旦成立,不再以日主强弱论;【任铁樵注】"日主无根,全局气势偏于一方,无破格之神,方为真从"。

**从杀格判定步骤**(按序,任一步不满足即不取从):
1. 日主无根:天干(年/月/时)无透比劫,且四支藏干无无比劫。
2. 天干透官杀(正官/七杀)。
3. 月令扶从神:月支在官杀五行之旺相月【任铁樵注】"从神要旺,须得月令之气"。旺相月表:金 [申酉辰戌丑未]、木 [寅卯亥子]、水 [亥子申酉]、火 [巳午寅卯]、土 [辰戌丑未巳午]。
4. 地支官杀成势:成三合/三会官杀局,或本气为官杀的地支 ≥2。
5. 无印星化杀:印星透干且地支有强根 → 破格;月支本气为印星五行 → 提纲帮身破格。印星虚浮(透干无根)不破。
6. 无食伤制杀:食伤透干且地支有强根 → 克破;本气为食伤的地支 ≥2(排除已合化为官杀局之地支)→ 克神成势。食伤虚浮不破。

**从财格判定步骤**(按序):
1. 日主无根(同上)。
2. 天干透财星(正财/偏财)。
3. 月令扶从神(财星旺相月,同上表)。
4. 地支财星成势:成三合/三会财局,或本气为财星的地支 ≥2。
5. 无印星帮身(同从杀格第 5 步)。
6. 无比劫夺财:比劫透干且有强根 → 克财破格;本气为比劫的地支 ≥2(排除已合化为财局之地支)→ 克神成势。比劫虚浮不破。
7. 官杀不泄财:官杀透干且有根、又无食伤制杀 → 财党杀,不取从财;本气为官杀的地支 ≥2 且官杀未透 → 泄财成势。官杀虚浮不破。

强根表(第 5-7 步用):土 [辰戌丑未午]、金 [申酉]、水 [亥子]、木 [寅卯]、火 [巳午]【本系统决策】。

### 0.3 化格判定条件(按序,任一步不满足即不取化)

五合化气映射:甲己化土(甲→戊/己→己)、乙庚化金(乙→辛/庚→庚)、丙辛化水(丙→壬/辛→癸)、丁壬化木(丁→乙/壬→甲)、戊癸化火(戊→丙/癸→丁)。

1. 日主参与五合:年/月/时干有日主之合神。
2. 化神透干:合神透干即化神透干(合神五行=化神五行)。
3. 月令支持化神:月支在化神旺相月【任铁樵注】"化神要昌,须得月令之气"。表同 0.2 第 3 步。
4. 化神有强根:地支成化神三合/三会局,或地支有化神强根。强根表:土 [辰戌丑未午]、金 [申酉]、水 [亥子]、木 [寅卯]、火 [巳午]。
5. 无克破化神(克化神之五行:土克水、水克火、火克金、金克木、木克土):
   - 克神透干且克神在地支有根或成局 → 克破;
   - 月支本气为克神 → 提纲克破;
   - 本气为克神的地支 ≥2 → 克神成势;
   - 克神虚浮(透干无根、地支不成势)不破。

依据:【滴天髓原文】"化得真者只论化,化神还有几般话";【任铁樵注】化神须月令之气、须有强根、须无克破。

## 第一章 · 取格(定格局名)

### 1.1 基础公理

1.1.1 格从月令取。格神必须来自月支——月支藏干透干,或月支藏干会支成局。天干上有但不来自月支的字,不能取为格神。【沈孝瞻原文·卷一】"八字用神,专求月令,以日干配月令地支……格局分焉。"

1.1.2 八格类型:正官、七杀、正财、偏财、正印、偏印、食神、伤官、建禄月劫、阳刃。

内部统称:官格/杀格(官杀分开)、财格(含正/偏)、印格(含正/偏)、食神格、伤官格、建禄月劫格、阳刃格。
展示名:正官格/七杀格/正财格/偏财格/正印格/偏印格/食神格/伤官格/建禄月劫格/阳刃格。
【沈孝瞻原文·卷一+卷四十三+卷四十五】

1.1.3 取格阶段不计算合化、冲、生克等作用关系,纯看月令藏干透干/会支定格名。(作用关系在成败阶段才引入。)【本系统决策】

### 1.2 取格判定流程(按顺序,命中即定)

**B.2 补充【本系统决策】**:会支成局所得十神若为比肩/劫财(会局五行与日主同五行),比劫不可独立成格,回落按月支本气取格(B.3)。

预备:确定日主(日干)、月支、月支藏干(本气/中气/余气,查1.3藏干表)。

第一步:判断月支本气对日主的十神。

第二步分流:月支本气是不是比劫(比肩/劫财)?

**分支A — 月支本气是比劫(日主五行当令)**

【沈孝瞻原文·卷八】"日与月同,本身不可为用,必看四柱有无财官杀食透干会支,另取用神。"

A.1 日主为阳干 且 月支 = 该日主的帝旺位(刃位)→ 阳刃格。(各阳干刃位:甲→卯、丙→午、戊→午、庚→酉、壬→子。阴干无阳刃。)【沈孝瞻原文·卷四十三】"阳刃者……禄前一位,惟五阳有之。"

A.2 其他比劫当令情况(月支是禄位、或本气比劫但非禄非刃的杂气土月)→ 建禄月劫格。【沈孝瞻原文·卷四十五】"建禄与月劫,可同一格,不必加分。"(建禄月劫格本身不可为用,用神另取,见第四章4.7。)

**分支B — 月支本气不是比劫(财/官/印/食伤)**

B.1 透干取格:看月支藏干是否透干(出现在年/月/时干)。只有透出的藏干是八格十神(正官/七杀/正财/偏财/正印/偏印/食神/伤官)才能取为格;若透出的藏干是比肩或劫财,该字不能独立成格(八格无比肩格/劫财格),跳过它,继续看其他透出的藏干。
- 本气透(且为八格十神) → 取本气为格。【通行惯例:本气优先,非真诠明文】
- 本气不透或本气为比劫被跳过、中气或余气透(且为八格十神) → 取透出的中/余气为格。
- 多个藏干都透(且都为八格十神) → 取"有情"者(顺而相成)。【沈孝瞻原文·卷十六】"一透则一用,兼透则兼用……合而有情者吉。"
- 若月支藏干中能成格的(非比劫的)都不透 → 落B.3仅以本气论。(注:分支B的前提是月支本气非比劫,故B.3取本气必能取到八格十神。)

B.2 会支取格:月支与其他地支三合/三会成局(三支齐全)→ 取"会成五行对日主的十神"为格(非月支本气十神)。会支成局指三合三会三支齐全,半合(两支)不作为会支取格的依据。透干+会支并存则并用。【沈孝瞻原文·卷十六】"逢申与子会局,则用水印。"只用三合三会,不用"冲库开库"。【沈孝瞻原文·卷十七】反对"财官入库不冲不发"。

B.3 不透不会 → 仅以本气论(取本气那个格)。【徐乐吾评注·非沈孝瞻原文】卷十六评注"不透不会,则仅以土论。"

### 2.2 判断规则(块2)

2.2.1 解冲:相冲的支被第三支会合(三合/三会/六合)牵制 → 冲被解除。仅会合解冲,不用刑冲解冲。【沈孝瞻原文·卷七】"三会六合,可以解之";【本系统决策】不采"以刑冲解冲"。

2.2.2 合化成立条件:天干五合 / 地支六合,只有当合化所成的五行(化神)在天干透出时,才论"合化成立"(合化成那个五行);化神不透 → 只合不化(合而不化)。【通行惯例·从严取化神透干为准】

2.2.3 合化/合绊对用神的效果:合化成立 = 羁绊牵制,被合的字仍在、仍起作用,只是受牵连、层次受损;不是被合的字消失。【本系统决策】

2.2.4 取格不算作用关系,成败才论生助克泄合冲。【本系统决策】

2.2.5 食神制杀:命局有食神且食神克制七杀(食神透干克杀)→ 算"杀有制"。

2.2.6 印星化杀:命局有印,七杀生印、印生身(杀印相生)→ 算"杀有化"。

【沈孝瞻原文·卷九】"身强七煞逢制,煞格成也"(食制);印化杀属顺逆相生。

## 第三章 · 成败总则

### 3.1 三态定义

成格:满足该格成格条件,且无破格。
不成格:成格条件未满足,但也未触发破格条件(待定/孤弱)。
破格:触发该格破格条件,且无救应。

### 3.2 破格与救应总则

3.2.1 任何破格条件,都必须"触发 + 无救应"才算破格。触发但有救应 → 不破。

3.2.2 通用救应手段(任一适用即解对应破坏):

- 会合解冲:用神被冲,冲支被会合牵制 → 冲解。
- 印制伤:伤官见官,有印制伏伤官(且印未被财克)→ 护官。
- 财通关:伤官见官,有财通关(伤生财、财生官)→ 化敌为友。
- 食制/印化:七杀逢财党、官杀混杂,有食神制杀或印星化杀 → 清局/制伏。
- 合去忌神:混杂的官/杀被合去(合化或合绊)→ 清。

3.2.3 救应本身可被再破坏(如"印护官"但印被财克 → 救应失效)。

3.2.4 刑不参与破格、也不参与救应。【沈孝瞻原文·卷七阙疑】

3.2.5 补充①·合绊算制约:凶神(七杀等)被合绊,视为一种制约(凶性减弱、攻身力卸),效果类似制伏/化解,可使"凶神无制"的破格不成立(但层次受损)。区别于"克制"(食神制杀那种直接克),合绊是"绑住"。【本系统决策】

3.2.6 补充②·用神被合去:任何格,其格神(用神)被合去(合化成他物、或被合绊到失去原作用)且无救 → 破格。【沈孝瞻原文·卷九"杂煞而合煞以清之"反向 + 本系统决策】

3.2.7 补充③·成败必须算地支合会局:判成败时,地支三合/三会/六合形成的五行力量,与天干透出的十神同等参与判定。地支会成官杀局/食伤局/财局等,即使天干不透,该力量真实存在,参与党杀/制化/夺财等判定。不能只扫天干找制化/破坏,必须同时看地支合会成的局。【沈孝瞻原文·卷十六(取格用会支)+ 本系统决策】

3.2.8 活跃十神:在判定格局成败时,参与作用的"活跃十神"仅限于满足以下条件之一者:(a) 天干透出;(b) 地支三合、三会成局,且合化后的十神。仅藏于地支而不透干、不成局的十神,一律不作为成败判定的"作用方",其作用仅为给透干的同类十神提供"根气"。【本系统决策】

3.2.9 论势不论星:凡地支三合、三会成局,皆按"整体气势"论,不拆分为阴阳十神。例如,申酉戌会金局,属"官杀成局",不拆为"正官局"与"七杀局";申子辰会水局属"财星成局",不拆为"正财局"与"偏财局"。会局负责论"势"(力量的强弱与攻击性),天干透出之星负责论"星"(精度更高的混杂、清浊等判定),两者层面不同,绝不混用。【本系统决策】

3.2.10 简化决策·暂不做三次检查:救应可被再破坏(3.2.3),但**本系统止步于二次检查**——检查到"救应被破坏"即判救应失效,不再检查"破坏救应者又被制伏"的第三层。以下七处已按此执行【本系统决策】,若未来需要细化,逐条在此登记并补代码与测试:

1. 会合解冲:解冲的合/会被冲散 → 直接判解冲失效(不再查"冲散之冲再被合解")。
2. 印制伤(护官/佩印通用):印被财克 → 判印救失效(不再查比劫制财护印)。
3. 财通关:财被比劫夺 → 判财通关失效(不再查官杀制比劫护财)。
4. 食神制杀:食神被偏印夺 → 判食制失效(不再查财制枭护食)。
5. 印星化杀:印被财破 → 判印化失效(不再查比劫制财护印)。
6. 合去忌神:争合(多干争一合神)→ 暂不判破格,留检测点待细化。
7. 财破印(贪财坏印)的救应检查:财透而无比劫/官杀即判破,不查"比劫被官杀制"的第三层。

## 第四章 · 八格成败(逐格)

通用:每格破格条件均需"触发+无救应"(套3.2)。救应手段见3.2.2。成败必算地支合会局(3.2.7)。

### 4.1 正官格(顺用,喜生护)

【沈孝瞻原文·卷一】"财喜食神以相生,生官以护财";【卷九】"官逢财印……官格成也"。

成格:有财生官 OR 有印护官。
不成格:财印俱无、孤官无辅,未破格。
破格(任一+无救):①伤官见官(伤官透干克官,无印制伤、无财通关);②正官被冲(无会合解);③正官被合去(合化后非官);④官杀混杂(七杀混局)无制化。

### 4.2 七杀格(逆用,喜制化)

【沈孝瞻原文·卷一】"七煞喜食神以制伏,忌财印以资扶";【卷九】"身强七煞逢制,煞格成也""七煞逢财无制,七煞格败也"。

成格:食神制杀 OR 印星化杀。
不成格:无食制无印化,且未被财党杀、未会成官杀局、未被冲。
破格(任一+无救):①财生杀党杀无制化;②地支三合/三会成官杀局、杀势极旺而无制化(凶神成局必患):此条件负责判定地支合局所形成的官杀气势,与天干透出之星无关;③官杀混杂无制化:天干层面,正官与七杀同时透出,且无制化(食制/印化)。本条件仅论天干并透之星,不论地支合局之势;④七杀被冲。
钉死:七杀格中财生杀=破格方向(与正官"财生官=成格"相反)。

七杀格补充(层次,非成格门槛):七杀格用食神制杀时,日主身强则担杀有力、层次较高;日主中和或身弱则食制仍成立(格不破)、但层次受损。身强与否只影响层次高低,不影响成格成立(食制/印化仍按原条件判成格)。【沈孝瞻原文·卷九】"身强七煞逢制,煞格成也"(身强担杀为佳);【本系统决策】取层次参考方案——身强作层次参考,非成格硬门槛(保护中和/偏弱但食制有情的命局)。

### 4.3 财格(正/偏财统一判,顺用,喜食伤生、官护)

【沈孝瞻原文·卷一】"财喜食神以相生,生官以护财";【卷九】"财生官旺,或财逢食生……财格成也""财轻比重,财透七煞,财格败也"。

成格:财生官(官护财)OR 食伤生财(财有源)。
不成格:财孤(无食伤生、无官护),未被比劫夺尽。
破格(任一+无救):①比劫夺财(无食伤通关、无官杀制比劫);②财透七杀党杀(无制化);③财被冲。
钉死:财生七杀(党杀)=破格方向。

### 4.4 印格(正/偏印统一判,顺用,喜官杀生、食伤泄)

【沈孝瞻原文·卷一】"印喜官煞以相生,劫才以护印";【卷九】"印轻逢煞,或官印双全……印格成也""印轻逢财……印格败也"。

成格:官杀生印(官印/杀印相生)OR 印旺用食伤泄秀。
不成格:印孤(无官杀生),未被财破。
破格(任一+无救):①财破印(贪财坏印,无比劫制财、无官杀通关);②印被冲。
钉死:财对印=破印方向。
正偏印统一;枭神夺食归食神格写,印格不重复。

### 4.5 食神格(顺用,喜身旺生、食生财吐秀)

【沈孝瞻原文·卷一】"食喜身旺以相生,生财以护食";【卷九】"食神生财……食格成也""食神逢枭,食神格败也"。

成格:
① 食神生财(吐秀生财);
② 弃食就煞而透印（【沈孝瞻原文·卷九】"食带煞而无财，弃食就煞而透印，食格成也"）。条件：七杀活跃 + 印星活跃 + 无财星活跃。食神格同时见七杀和印星时，印夺食神（枭夺食），但同时七杀在则印可化杀生身，格局核心从食神转为杀印相生（徐乐吾评注："弃食就煞，以印化煞为用。虽月令食神，不再以食神格论矣"）。注意：必须有杀有印且无财，三条缺一不可；有偏印无杀仍是"枭神夺食"破格。

不成格:食神孤(不生财、未弃食就煞、未被枭夺)。
破格(任一+无救):①枭神夺食(偏印克食,无财制枭、无杀印成格);②食神被冲。
救应:枭夺食→财制枭(财克偏印护食)，或弃食就煞透印(有杀时印不夺食反化杀)。

### 4.6 伤官格(逆用,用法多样)

【沈孝瞻原文·卷一】”伤官喜佩印以制伏,生财以化伤”;【卷九】”伤官生财,或伤官佩印……或伤官带煞而无财,伤官格成也””伤官非金水而见官……伤官格败也”。

成格:
① 伤官生财；
② 伤官佩印——前置条件（【本系统决策·定性简化版】）：伤官旺（伤官透干 + 地支有长生/禄/旺强根，或三会/三合成伤官局）+ 印有根（印透干 + 地支有长生/禄/旺强根），否则降为不成格；
③ 伤官带杀无财——前置条件（【本系统决策·定性简化版】）：伤官旺 + 日主身弱或中和（身强则无需伤官引化、可直接担杀），否则降为不成格。

有印佩 = 印在干支出现 且 印未被财破。
有杀配 = 七杀透干 且 无食制、无印化、无合绊。

不成格:伤官孤(不生财、无印佩、无杀配),未见官破；或佩印/带杀前置条件不满足。
破格(任一+无救):①伤官见官(无印制伤、无财通关);②伤官被合去;③伤官被冲。
救应:伤官见官→印制伤 OR 财通关。
调候特例:金水伤官喜见官（【通行惯例/《穷通宝鉴》】金水伤官，调候为急，官星火可暖局，不忌见官，反为贵）。
判定条件:日主庚辛金 + 月令亥子丑 + 地支无巳午火根。伤官格见官时不破格，标注”金水伤官喜见官，调候为急，格局反贵”。

### 4.7 建禄月劫格(本身不可为用,用神另取)

【沈孝瞻原文·卷八+卷四十五】"日与月同,本身不可为用……另取用神""建禄与月劫,可同一格,不必加分,皆以透干支,别取财官煞食为用";【卷九】成败列举。

本质:格名定为建禄月劫,成败看天干所透的用神,套用对应格(官/杀/财/食伤)的成败规则(透官套官格、透杀套七杀格、透财套财格、透食伤套食/伤格)。本身无独立成败规则。
成格:透官逢财印 / 透财逢食伤(转劫生财)/ 透杀遇制伏 / 透食伤泄秀(无财官时,秀气)。
不成格:天干无财官杀食可取(纯比劫印),或透了但配套不全。
破格(任一+无救):透杀无制 / 透财被比劫夺尽 / 用神被冲或被合去。

### 4.8 阳刃格(仅五阳干、月支帝旺;逆用,喜官煞制、反喜财印、忌伤官)

【沈孝瞻原文·卷四十三】"刃宜伏制,官煞皆宜,财印相随尤为贵显……反喜财印,忌制伏";【卷九】"阳刃透官煞而露财印,不见伤官,阳刃格成也""阳刃无官煞,刃格败也"。

用神:以官杀为用(制刃者)。
成格:透官煞制刃,且不见伤官。(有财印相随护官煞=贵显。)
破格(任一+无救):①阳刃无官煞制(刃失制→破格,按原文"败");②官煞制刃但见伤官;③制刃的官煞被冲或被合去。
救应:伤官见官→印制伤 OR 财通关;官煞被冲→会合解。
方向(与七杀相反):阳刃喜官煞制、喜财印护、忌伤官。

调候特例:化刃为印（【沈孝瞻原文·卷四十三】"戊生午月，干透丙丁，支会火局，则化刃为印"）。
判定条件:日主戊土 + 月令午 + 天干透丙或丁 + 地支会火局(巳午未三会 或 寅午戌三合)。满足时取格为印格(正印/偏印)，patternGod标注"月支午(刃)化火印"，origin仍为"比劫当令"。
