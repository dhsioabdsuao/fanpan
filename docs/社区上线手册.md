# 社区功能上线手册(CloudBase 版)

> 2026-09-01 · 后端为腾讯云开发 CloudBase(原选 LeanCloud 已宣布 2027-01-12 停服并已停止新应用创建,已迁移)

## 一、腾讯云控制台(约 20 分钟)

### 1. 注册与实名

1. 打开 https://cloud.tencent.com ,注册/登录腾讯云账号
2. 右上角账户 → **实名认证**(个人认证即可,手机号+身份证;短信服务硬前置)

### 2. 创建云开发环境

1. 进入云开发控制台:https://tcb.cloud.tencent.com
2. **新建环境**:
   - 环境名称:随意,如 `bazi`
   - 计费方式:选**免费体验环境**(0 元/月,3000 资源点/月;后续不够可升级个人版 ¥19.9/月)
   - 地域:选 **上海** 或广州(记下,后面要填 region)
3. 创建完成后记下**环境 ID**(形如 `bazi-1a2b3c`,环境卡片上)

### 3. 开启短信登录 + 生成 Publishable Key

1. 左侧 **身份认证 → 登录管理**:
   - 开启**短信验证码登录**(页面如有短信签名/模板要求,按提示完成配置)
2. 同页生成 **Publishable Key**(前端访问凭证,公开使用;真密钥勿放客户端)
3. 记下:环境 ID、地域、Publishable Key

### 4. 创建数据库集合 + 安全规则

1. 左侧 **数据库 → 新建集合**,依次创建 4 个:`Post`、`Annotation`、`UserStats`、`Report`
2. 每个集合 → **权限设置 → 自定义安全规则**,按下面 JSON 填入:

**Post**(全员可读,登录可写;客户端自律+举报兜底):
```json
{
  "read": true,
  "write": "auth != null"
}
```

**Annotation**(全员可读,仅作者可写):
```json
{
  "read": true,
  "write": "auth != null && doc.authorUid == auth.uid"
}
```

**UserStats**(仅本人可读写,文档 id = uid):
```json
{
  "read": "auth != null && doc.uid == auth.uid",
  "write": "auth != null && doc.uid == auth.uid"
}
```

**Report**(客户端不可读,登录可写,后台处理靠控制台):
```json
{
  "read": false,
  "write": "auth != null"
}
```

> 若控制台规则编辑器提示语法差异,以其内置变量提示为准(auth.uid / doc)。

### 5. 填应用配置

编辑 `bazi-app-sdk52/services/cloudbase-config.ts`:

```ts
export const CLOUDBASE_CONFIG = {
  env: '你的环境ID',            // 如 bazi-1a2b3c
  region: 'ap-shanghai',        // 环境地域(上海 ap-shanghai / 广州 ap-guangzhou)
  accessKey: '你的PublishableKey',
};
```

## 二、种子内容(防止冷启动空广场)

### 6. 创建腾讯云 API 密钥(仅本机脚本用)

1. 腾讯云控制台 → 搜索「访问管理」→ **API 密钥管理 → 新建密钥**
2. 记下 SecretId / SecretKey(**切勿提交到仓库**)

### 7. 跑种子脚本

```bash
cd /Users/apple/Desktop/bazi-site
TCB_ENV=你的环境ID TENCENT_SECRET_ID=xxx TENCENT_SECRET_KEY=xxx \
  node scripts/seed-community.mjs
```

期望输出:`✓ 帖子「求看事业方向…」(庚辰 壬午 甲辰 庚午)`… 最后一行 `完成:新帖 8 条,批注 17 条`。

再到控制台 数据库 → Post 集合核对 8 行数据;点开任一行确认 `draft` 字段内**没有 minute/province/city 等键**(脱敏人工验收点)。

## 三、开发环境:模拟器快速预览(一次性安装 dev client)

> Expo Go 无法运行社区功能(CloudBase 适配器依赖 MMKV 原生模块)。
> dev client 装进模拟器只需一次;之后 `npx expo start` 按 `i` 秒级热更新,与 Expo Go 体验一致,不用每次走 EAS/真机。

### 方案 A:EAS 云构建(推荐,无需本地 CocoaPods)

1. 在 `bazi-app-sdk52/eas.json` 的 profiles 里加一个模拟器构建档:
```json
"development-simulator": {
  "extends": "development",
  "ios": { "simulator": true }
}
```
2. 构建(约 20-40 分钟,云上执行):
```bash
cd bazi-app-sdk52 && eas build --profile development-simulator --platform ios
```
3. 构建完成后下载 `.app`(或 `.tar.gz` 解压),**把 .app 拖进打开的 iOS 模拟器窗口**即可安装
4. 日常开发:
```bash
npx expo start
# 按 i → 在模拟器里以 dev client 打开 → 保存代码即热更新
```
5. 只有**新增/卸载原生依赖**时才需要重新构建(社区功能完工后基本不会再发生)

### 方案 B:本地构建(需先装 CocoaPods)

```bash
brew install cocoapods
cd bazi-app-sdk52 && npx expo run:ios
```
之后同样 `npx expo start` + 按 `i`。

### 真机验证(偶尔需要时)

```bash
eas build --profile development --platform ios
```
构建完成后用手机扫二维码安装 dev client,同一 WiFi 下 `npx expo start` 即可连上。

## 七、应急与后台操作

- **举报处理**:控制台 数据库 → Report 集合查看;对违规内容到 Post/Annotation 集合直接删除该行
- **封号/限流**:身份认证控制台可禁用用户;敏感词仅客户端过滤,兜底靠举报+后台删除(远期可接天御内容安全 API)
- **数据导出**:控制台 数据库支持导出 JSON,备份或迁移随时可做
