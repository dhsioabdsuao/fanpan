## 第二章 · 正格体系喜忌规则

### 2.1 调候调度(最高优先级,用户已确认)

- 气候**极端**(火炎土燥/金寒水冷)→ **调候救治元素列第一**(救急):火炎土燥救治元素=水;金寒水冷救治元素=火。【穷通宝鉴·调候为急】
- 气候**适中**(寒暖适中)→ 格局机制用神列第一,调候表元素仅作参考列后。

### 2.2 格局机制用神(由成败层条件推导,非格神)

| 格局 | 成格情形 → 机制用神元素 | 不成格/破格 → 补救方向 |
|---|---|---|
| 官格 | 财生官→财;印护官→印 | 财、印 |
| 杀格(八格) | 食神制杀→食伤;印星化杀→印 | 食伤、印。**格神七杀元素绝不在喜用中**【子平真诠·卷九"身强七煞逢制"】 |
| 财格 | 食伤生财→食伤;财生官→官 | 食伤、官 |
| 印格 | 官杀生印→官杀;食伤泄秀→食伤 | 官杀、食伤 |
| 食神格 | 食神生财→财;弃食就煞而透印→印(杀印相生) | 财 |
| 伤官格 | 伤官生财→财;伤官佩印→印;伤官带杀→杀;金水伤官喜见官→官(火) | 财、印 |
| 建禄月劫 | 另取用神套对应格规则(透杀:杀元素为机制用神【建禄月劫另取用神与八格格神不同,可入喜用】) | 按所透十神 |
| 阳刃格 | 官杀制刃→官杀 | 官杀 |

依据:各格成格机制取自《子平真诠》卷九与《格局规格书》第四章;「建禄月劫另取用神可入喜用」为【本系统决策】——建禄月劫格神是月令比劫,另取的官杀/财/食伤是机制用神本身。

### 2.3 通关

五行流通的**通关元素**列后(气候极端时列调候之后)【通行惯例·病药】。

### 2.4 忌神

忌神 = 以下三类并集(剔除与喜用冲突者,见 2.5):

1. **结构忌神**(逐格):官格忌食伤元素;杀格忌财元素+官杀元素(混杂、党杀);财格忌比劫元素;印格忌财元素;食神格忌印元素;伤官格忌官杀元素;建禄月劫/阳刃忌比劫元素(比劫当令为病)【本系统决策】;从格/化格见第一章相应破格因素。
2. **过旺失衡**:五行计数 ≥ 3 且不在喜用中【本系统决策】。
3. **气候方向性忌神**:火炎土燥忌火(增燥);金寒水冷忌水(增寒)。【本系统决策,2026-08-29 用户确认】

### 2.5 冲突裁决(调候/通关遇忌神)

1. **调候救治元素**(2.1 的救急元素)∈ 忌神 → 保留在喜用中(救急优先),从忌神中剔除。
2. **调候表其余参考元素** ∈ 忌神 → **从喜用中剔除**(格局优先),记录说明:与气候方向性忌神冲突时说明"气候已足不需补"(如"调候原需火,但命局火候已足,火反增燥,不再补");与格局忌神/过旺冲突时说明"格局优先,不列喜用"。
3. **通关元素** ∈ 忌神 → 保留在喜用中(通关优先),从忌神中剔除。

所有冲突生成冲突记录 `{元素, 角色, 冲突对象, 裁决, 说明}`,所有文案统一呈现该说明。【本系统决策·沿《穷通宝鉴》调候为急之旨】

### 2.6 不变量(强制,测试断言)

1. `喜用 ∩ 忌神 = ∅`;
2. 八格杀格:格神元素不在喜用中;
3. 规则轨迹(ruleTrace)非空,记录每条应用的规则与依据。
