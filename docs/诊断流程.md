# 子平八字诊断流程(总纲)

> 版本:v1.0(2026-08-29 用户确认)
> 本文件是软件诊断流程的**唯一总纲**。《格局规格书》《强弱规格书》《喜忌规格书》均引用本文件,与本文件冲突时以本文件为准。
> 流程原则:**单向数据流,环环相扣**。每层只消费上游的结构化结论,禁止调用下游层、禁止重复上游层的计算。

## 一、十层流程

```
L0 排盘层 ──→ L1 命局事实层 ──→ L2 全局性质层 ──→ L3 强弱层(仅正格)
                                        │                    │
                                        ↓                    ↓
                                   L4 成败层(逐格)     L5 调候层 / L6 流通层(并列)
                                        └──────┬─────────────┘
                                               ↓
                                        L7 喜忌综合层(全软件唯一喜忌出口)
                                               ↓
                                        L8 行运层(大运流年引动)
                                               ↓
                                        L9 神煞层(纯标注,不参与判定)
                                               ↓
                                        L10 文案层(只翻译结构化结论)
```

### L0 排盘层(原材料,零判断)
输入:出生时间 + 地点 + 性别 → 真太阳时校正 → 四柱(节气换月、立春换年、早/晚子时)→ 大运流年。
输出:纯事实命盘数据(`BaziResult`)。本层不得包含任何"判断"。

### L1 命局事实层(客观统计,全软件只此一份)
- 五行计数:统一 8 分制(4 干 + 4 地支本气),存于 `bazi.elementCount`;其他层禁止自建计数口径(流通层的全藏干计数、强弱层的加权力量是**该层内部量**,不得外泄为判断依据)。
- 日主根气表(禄旺/中气/余气/无根)、十神分布、天干五合、地支六合/三合/三会/冲/刑/害——**只记录事实(谁合了谁),不下结论**。
- 月令旺相休囚死状态。

### L2 全局性质层(先定"论什么体系",顺序固定、命中即止)
```
① 化格?(五合 + 月令支持 + 无克破)         → 命中即进入「化神体系」
② 从格?(日主无根 + 从神得令成势 + 无破格)   → 命中即进入「从神体系」★不依赖强弱
③ 化刃为印特例?
④ 正格体系(月令取格:透干 → 会支 → 本气;建禄/阳刃另取用神)
```
输出:格局类别 + 格神 + **判定轨迹**(judgementTrace,每步记录依据)。
本层决定后续所有层用哪套规则:化格只论化、从格只论从、正格才走 L3–L6。

### L3 强弱层(仅正格体系使用;化格/从格跳过)
得令(月令旺相休囚死)+ 得地(强根/弱根)+ 得势(加权)→ 身强/中和/身弱。
比值落在阈值 ±0.05 模糊带内归「中和」。
**用途限定:成败判定的参考信息与文案展示。禁止作为任何层的硬门槛。**

### L4 成败层(逐格判定,《子平真诠》卷九体系)
每格有成格条件清单(结构化:`{名称, 说明, 是否满足}`)+ 救应体系(相神/喜神/忌神/仇神)+ 特例(金水伤官喜见官等)。
输出:成格/不成格/破格 + 相神 + 条件清单 + 特例标记。
本层是喜忌推导的直接依据;`reason` 文案仅供展示,**禁止被下游解析**。

### L5 调候层(穷通宝鉴体系,独立维度)
气候类型(火炎土燥/金寒水冷/寒暖适中,含冬夏安全闸)+ 120 条调候用神表。
输出:气候类型 + 调候天干/五行。**不修改格局层结论,冲突留到 L7 裁决。**

### L6 流通层(病药视角)
源头(旺者)→ 流向 → 淤堵点 → 通关元素。
输出:淤堵五行 + 通关五行,作为第三类参考用神。

### L7 喜忌综合层(全软件唯一喜忌出口)
仲裁规则(详见《喜忌规格书》):
```
① 化格成立  → 喜化神 + 泄秀;调候仅标注不参与排序
② 从格成立  → 喜从神 + 泄秀;调候仅标注
③ 气候极端  → 调候元素列第一(救急)
④ 气候适中  → 格局用神(机制用神)列第一
⑤ 通关      → 列后
⑥ 忌神      → 结构忌神(逐格) ∪ 过旺失衡(≥3) ∪ 气候方向性忌神(火炎土燥忌火、金寒水冷忌水)
⑦ 冲突裁决  → 调候/通关遇忌神时保留在喜用,生成统一冲突说明
```
输出:喜用(有序)/ 忌神 / 主喜 / 次喜 / 冲突说明 / 规则轨迹。
**铁律:喜用 ∩ 忌神 = ∅;格神(如七杀)永不在喜用中。**
发展方位、行业、城市、发展建议**全部只读本层输出**。

### L8 行运层(大运流年引动)
大运干支引动了 L7 的哪些喜用/忌神 → 顺逆表述(中性化);流年互动(天合地合/天克地冲/伏吟/岁运并临)。
**不重新判断喜忌,只记录"引动了喜忌中的谁"。**

### L9 神煞层(纯标注,不参与判定)
神煞独立查询展示。**神煞不参与 L2–L8 任何判定**【本系统决策·子平主流】。

### L10 文案层(只翻译,不判断)
每句论断必须对应上游一个结构化真值(「论断→真值」对照表);同一结论全软件同一文案;禁止吉凶绝对化表述。

## 二、结果页排版(两端一致,按十层流程排列)

```
① 命盘总览      四柱 + 日主 + 五行分布(合并展示)
② 格局定位      格神 + 判定轨迹(可展开"为什么取这个格")
③ 日主强弱      仅正格显示;化格/从格显示"论化/论从,不以身强弱论"
④ 格局成败      成格条件清单(逐条 √/×)+ 相神 + 特例说明
⑤ 调候          气候类型 + 调候用神 + 与喜忌冲突标注
⑥ 五行流通      淤堵点 + 通关元素
⑦ 喜忌总览      全盘唯一结论:喜用(有序)/ 忌神 / 冲突说明 ★核心卡片
⑧ 综合解析      命局叙事 + 格局解析 + 发展建议(由结构化结论翻译)
⑨ 大运流年      大运表 + 流年互动 + 每步大运引动了哪些喜忌
⑩ 事业指引      行业/方位/城市 —— 纯翻译⑦
⑪ 体质倾向      纯翻译
⑫ 神煞          纯标注区,注明"不参与诊断判定"
⑬ 生肖等静态内容 尾部
```

- 每个判定卡片带「判定依据」展开项,显示规则轨迹,可对照规格书核验。
- 视觉风格(暖金配色、毛玻璃质感)保持不变,仅重组卡片次序与内容。
- 实施时机:S6(逻辑层全部修完后),与 analyze() 统一管线一并落地。

## 三、金标准命例制度

- 金标准命例库:`lib/__tests__/goldens.ts`。
- 来源分档:`user-confirmed`(用户人工核对,最高权威)/ `classical-text`(古籍例题)/ `draft`(待确认,测试跳过)。
- 每个命例的 `expected` 是"最终应当判定为什么",不是"当前代码判什么"。
