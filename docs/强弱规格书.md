## 第一章 · 三要素判定

### 1.1 得令(月令是否帮扶日主)

两条件满足其一即得令:
1. **季节旺相休囚死**:日主五行在月令季节的强度分值 ≥ 2(旺或相)。分值表【本系统决策】(旺=3 相=2 休=1 囚=0.5 死=0):
   - 春(寅卯辰月):木旺 3、火相 2、水休 1、金囚 0.5、土死 0
   - 夏(巳午未月):火旺 3、土相 2、木休 1、水囚 0.5、金死 0
   - 秋(申酉戌月):金旺 3、水相 2、土休 1、火囚 0.5、木死 0
   - 冬(亥子丑月):水旺 3、木相 2、金休 1、土囚 0.5、火死 0
2. **月支本气帮扶**:月支本气十神为比肩/劫财/正印/偏印(与取格同口径的藏干表)。

依据:【任铁樵注】月令得时为旺;【徐乐吾注】印绶为生、比劫为助;"月令提纲,譬之宅也"【滴天髓正文】。分值具体数字为【本系统决策】。

### 1.2 得地(日主在地支是否有根)

- **强根**:任一地支藏干含日主同五行字,且该支为该五行任一阴/阳干的**禄、帝旺、长生**位(甲禄寅/乙禄卯/丙禄巳/丁禄午/戊禄巳/己禄午/庚禄申/辛禄酉/壬禄亥/癸禄子;帝旺:甲卯/丙午/戊午/庚酉/壬子及阴干阳位互换;长生:甲亥/乙午/丙寅/丁酉/戊寅/己酉/庚巳/辛子/壬申/癸卯)。
- **弱根**:地支**本气**与日主同五行,但非禄旺长生位。
- **微根**(不计):地支中气/余气与日主同五行。
- 得地 = 强根 ≥ 1 处,**或**弱根 ≥ 2 处【本系统决策】。

依据:【任铁樵注】"长生禄旺,根之重者也;墓库余气,根之轻者也""干多不如根重"。强/弱/微三档划分与 ≥2 弱根合并规则为【本系统决策】。

### 1.3 得势(全局帮扶与克泄耗的加权对比)

- 帮扶方:印(正/偏印)+ 比劫(比肩/劫财);克泄耗方:食伤 + 财 + 官杀。日主自身不参与计数。
- 权重表【本系统决策】:
  - 天干:年干 1.0、月干 1.5、时干 1.0(月干为纲)。
  - 地支藏干 = 位置权重 × 深浅权重:位置 年支 0.5 / 月支 0.8 / 日支 1.0 / 时支 0.6(日支最重要,月支其次);深浅 本气 1.0 / 中气 0.6 / 余气 0.3。
  - 合会局:地支成三会局 +3、三合局 +2,作为该五行虚拟字计入;若为帮扶方,再 ×1.5【本系统决策】。六合不加权。
- 得势 = 帮扶加权 > 克泄耗加权 × 1.2;失势 = 克泄耗加权 > 帮扶加权 × 1.2;其余均衡。±20% 门槛为【本系统决策】。

依据:【任铁樵注】"得势=党多援众";【徐乐吾注】"生助多者为强,寡者为弱"。全部权重数字为【本系统决策】。

## 第二章 · 合成三档

加权比例 ratio = 帮扶加权 ÷ 克泄耗加权(克泄耗为 0 时,帮扶 > 0 视为 ∞,否则 1)。

分档阈值【本系统决策】:0.6(强线)、1.3(强线·地势档)、1.5(强线·兜底/弱线·失令失地)。
**模糊带【本系统决策】:比值落在任一阈值 ±0.05 内时,一律归「中和」**——消灭"0.598 vs 0.6"式阈值悬线,保证小扰动不翻转结论。

判定顺序(命中即定):
1. 得令 且 得地 且 得势 → **身强**(三要素全帮)【任铁樵注】"得时得地得势,此三者不可偏废"。
2. 失令 且 失地 且 失势 → **身弱**(三要素全不帮)。
3. 得令 且 得地 → ratio ≥ 0.65 → 身强;否则**中和**。
4. 失令 且 失地 → ratio ≤ 1.45 → 身弱;否则**中和**。
5. 得令 且 得势 → **身强**(根基在别处)。
6. 得地 且 得势 → ratio ≥ 1.35 → 身强;否则**中和**。
7. 其余组合 → ratio ≥ 1.55 → 身强;ratio ≤ 0.55 → 身弱;否则**中和**。

依据:2.1/2.2 从严门槛取【本系统决策】"三者一致才判强弱"精神;2.3-2.7 的中间态细分与全部阈值为【本系统决策】,呼应【滴天髓原注】"旺中有衰、衰中有旺"。

## 第三章 · 使用边界

- 本模块只做"强弱"维度;化格/从格命盘**不使用**强弱判定(只论化/只论从,见《格局规格书》第〇章)。
- 其他模块(成败、喜忌、文案)可读取 level 作参考,但**不得以 level 为硬门槛改变格局判定结果**。
- 输出三档:身强/中和/身弱,附得令/得地/得势三项事实与加权明细(理由串),供展示与核对。
