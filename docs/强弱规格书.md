# 子平强弱规格书 v1.0

## 元信息

版本:v1.0
适用范围:判定日主强弱(身强 / 中和 / 身弱),为格局成败的暂缓特例(如身强担杀、财轻比重等)提供强弱依据,同时作为独立展示项。
流派与依据:

总纲引《滴天髓》正文:"能知衰旺之真机,其于三命之奥,思过半矣。"
主体操作依据为任铁樵《滴天髓阐微》的"得时、得地、得势"体系。
术语边界引徐乐吾《滴天髓补注》:"强弱从生助言,印绶为生,比劫为助,生助多者为强,寡者为弱。"
量化与合成细节古籍未给,凡此类标【本系统决策】或【通行惯例】,不假装有古籍背书。


依据等级(从高到低):【滴天髓正文】>【任铁樵注】/【徐乐吾注】>【通行惯例】>【本系统决策】。
输出:身强 / 中和 / 身弱(三档,定性判断,不打分、不量化)。
与旺衰的关系:徐乐吾区分"旺衰"(从月令分)与"强弱"(从生助分)。本模块只做"强弱"维度;月令得令与否作为强弱判断中的一项要素纳入,不单独拆出"旺衰"维度展示。

## 第一章 · 三要素判定

判定日主强弱,看三个要素:得令、得地、得势。
### 1.1 得令(月令是否帮扶日主)
只看月支本气十神(与取格口径一致)。

得令:月支本气十神对日主是比肩、劫财、正印、偏印(帮扶)。
失令:月支本气十神对日主是食神、伤官、正财、偏财、正官、七杀(克泄耗)。

依据:【任铁樵注】月令得时为旺;【徐乐吾注】印绶为生、比劫为助;月令权重最重——【滴天髓正文】"月令提纲,譬之宅也"。
注:辰戌丑未等杂气月也一律按"本气十神是否为比劫/印"判得令,不开特例。
### 1.2 得地(日主在地支是否有根)
看四个地支的藏干中,有没有与日主同五行的字(即"根")。第一版只分有根 / 无根两档,不细分重根轻根。

得地(有根):四地支藏干中,任一藏干含与日主同五行的字。
失地(无根):四地支藏干中,完全没有与日主同五行的字。

依据:【任铁樵注】"长生禄旺,根之重者也;墓库余气,根之轻者也""干多不如根重"。(重根轻根的细分第一版暂不做,只分有无。)
### 1.3 得势(全局帮扶与克泄的多寡)
统计全局(四天干 + 四地支藏干)中,帮扶日主的力量与克泄耗日主的力量的多寡对比。

帮扶方:印(正印/偏印)+ 比劫(比肩/劫财)。
克泄耗方:食伤(食神/伤官)+ 财(正财/偏财)+ 官杀(正官/七杀)。
得势:帮扶方个数 多于 克泄耗方个数。
失势:帮扶方个数 少于 克泄耗方个数。
均衡:两者相当。

计数规则:

日主自身不参与计数(日主是"我",不是"我的党")。只数天干与地支藏干中除日主以外的字。
天干每个算1,地支藏干每个算1,权重相同(第一版简化,不区分天干与藏干权重)。

依据:【任铁樵注】"得势=党多援众";【徐乐吾注】"生助多者为强,寡者为弱"。计数方法古籍未给,为【本系统决策】。
## 第二章 · 合成三档

判定原则(极简):只在三要素一致指向时判强 / 弱,任何不一致 → 中和。
### 2.1 身强
三要素全部帮扶 → 身强:得令 且 得地 且 得势。
依据:【任铁樵注】"得时得地得势,此三者不可偏废";【本系统决策】取"三者全帮"为身强门槛(从严)。
### 2.2 身弱
三要素全部不帮 → 身弱:失令 且 无根 且 失势。
依据:【任铁樵注】"失时失势失地,偏枯太过";【本系统决策】取"三者全不帮"为身弱门槛(从严)。
### 2.3 中和
其余所有情况 → 中和:三要素不全一致(有的帮、有的不帮),一律中和。
依据:【本系统决策】极简原则——只在三要素一致时判强弱,不一致归中和(对应"待定"中间态);呼应【滴天髓原注】"旺中有衰、衰中有旺"的辩证。
